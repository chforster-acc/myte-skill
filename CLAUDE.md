# Workspace Instructions

## Presentation Style Guide (Accenture CEE)

When creating presentations, slides, or visual documents, follow these style conventions
derived from the Accenture CEE Townhall template.

### Colors

| Role             | Value / Description                        |
|------------------|--------------------------------------------|
| Primary accent   | `#A100FF` — Accenture signature purple     |
| Background dark  | `#1A0033` — deep aubergine/dark purple     |
| Background slide | `#0A0014` — near-black with purple tint    |
| Header bar       | `#000033` — dark navy, thin blue top strip |
| Text primary     | `#FFFFFF` — white                          |
| Text secondary   | `#CCAAFF` — light lavender for subtitles   |
| Table row even   | `#2D0057` — mid-purple                     |
| Table row odd    | `#1A0033` — dark purple (same as bg)       |
| Table header     | `#7B00CC` — saturated purple               |

### Typography

- **Font family**: sans-serif; Accenture uses a custom grotesque — fall back to `Arial` or `Helvetica Neue`
- **Slide title**: Bold, ~28–32pt, white, left-aligned or centered top-right quadrant
- **Subtitle / purpose line**: Regular or italic, ~14pt, lighter purple or white, directly below title
- **Body / table text**: Regular, ~10–12pt, white, tight line-height
- **Navigation labels** (top bar): Small caps or uppercase, ~10pt, white

### Layout

- **Slide ratio**: 16:9 widescreen
- **Title block**: Top-right area of the slide; title in bold, subtitle directly below
- **Content**: Table/grid structures preferred for structured data — use alternating row shading
- **Column headers**: Solid `#7B00CC` background, white text, centered
- **Logo / branding**: Accenture `>` chevron mark — bottom-right or top-left corner
- **Speaker panel**: Bottom-left, dark overlay, circular avatar thumbnails + name + title
- **Navigation bar**: Full-width top strip, dark navy, white labels separated by `|`

### Tables & Grids

- Use alternating row colors (dark purple / mid-purple) for readability
- Column headers always in saturated purple with white text
- Cell content: white text, small font, left-aligned
- Borders: none or very subtle 1px darker-purple lines

### General Tone

- Clean, modern, corporate
- Minimal decorative elements — structure and color do the work
- Every slide should have a clear single title + one-line purpose/subtitle
- Prefer structured tables over bullet lists for dense information

### Accenture Brand Context

These slides are used in internal CEE (Central & Eastern Europe) Townhall / leadership events.
Audience: senior internal stakeholders and leadership. Tone is professional and data-driven.
